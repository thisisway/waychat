# 0005 — Licença AGPL-3.0

- Status: aceito (confirmado pelo responsável do projeto)
- Fase: 0

## Decisão

O WayChat é licenciado sob **GNU AGPL-3.0**. Quem oferecer o software como serviço pela rede precisa disponibilizar o código-fonte das modificações, o que impede forks fechados em SaaS sem contrapartida.

## Consequências

- Contribuições entram sob a mesma licença.
- Dependências devem ser compatíveis com a AGPL-3.0 (MIT, Apache-2.0, BSD, ISC e semelhantes). A verificação automática de licenças fica no backlog.
